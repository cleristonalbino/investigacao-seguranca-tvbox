# Documentação da investigação

Esta pasta reúne os principais materiais produzidos durante o projeto de investigação de segurança de uma TV Box comercializada como SMAR1 PRO e identificada como MXQ PRO.

Os documentos foram organizados para apresentar tanto os resultados de uma investigação real quanto um guia didático para quem deseja aprender a realizar esse tipo de análise por conta própria.

## 1. Relatório de investigação

**[Relatório de Investigação de Segurança - MXQ PRO (PDF)](Relatorio_Investigacao_TVBox_MXQ_a.pdf)**

Documento técnico que apresenta a investigação realizada no dispositivo, incluindo:

- Identificação do equipamento e informações de firmware.
- Análise de aplicativos e permissões Android.
- Reconhecimento de rede e testes de conectividade.
- Consulta à documentação regulatória.
- Evidências coletadas, limitações e avaliação de riscos.

O relatório registra os procedimentos realizados, os resultados observados e as conclusões sustentadas pelas evidências disponíveis.

## 2. Manual de investigação para iniciantes

**[Missão TV Box - Guia Completo de Investigação de Segurança (PDF)](Manual_Missao_TVBox_Investigacao_Seguranca_Iniciante_ARCADE.pdf)**

Material didático desenvolvido para pessoas que estão começando a estudar segurança da informação, Linux, redes e análise de dispositivos Android.

O manual apresenta uma jornada de investigação passo a passo, explicando:

- Como preparar um laboratório seguro.
- Como identificar hardware e características do dispositivo.
- Como investigar Android, aplicativos e permissões.
- Como utilizar ADB, Nmap e tcpdump.
- Como observar o comportamento de rede.
- Como explorar firmware, bootloader e interfaces de baixo nível.
- Como avaliar riscos e decidir se um dispositivo merece confiança.

Os comandos são apresentados com explicações sobre sua finalidade, funcionamento e interpretação dos resultados.

O objetivo é permitir que o leitor compreenda o processo e consiga reproduzi-lo de forma independente.

## Objetivo

Mais do que analisar um equipamento específico, este projeto busca transformar uma investigação prática em conhecimento compartilhável.

A proposta é incentivar o aprendizado independente, o pensamento crítico e a análise baseada em evidências, respeitando as limitações técnicas de cada procedimento.

**Investigar primeiro. Compreender depois. Concluir somente com evidências.**
